What this direction removes

  • DEL“Moment Miner” as a page identity — the feed survives as the New from video tab; the nav word “Moments” now means one thing
  • DEL“Backlog · 73” chip + “banked” label for legacy atoms — folded into the On-hand drawer as a self-liquidating section
  • DELStories stage machine Draft/Published for interview stories + the “Pieces” count column → Captured/Processed/Yielding + Yield
  • DELStoryDetail 4-step pipeline stepper
  • DELBatch-era copy: “a cluster of publish-ready drafts” (Stories empty state), “banked as backlog” + “from your backlog” (/week empty states), “73 in backlog” (pre-draft banner)
  • DELHeld P4's Library “Moments” tab — Library remains files only

Build order (supersedes the held P4 surface list): ① provenance at review (smallest, highest trust-per-line: moment_id → client + the quote block in week card/editor/inbox) → ② /week chip + drawer with copy sweep → ③ /moments unification (bank landing + tabs) → ④ Stories full reframe → ⑤ Home nudge. Each step mockup-covered above; each ships as its own PR batch through the normal gates. Reel-lane wiring (clip ↔ moment linkage) is build work the video-pipeline thread owns, but its UI home is now defined: the intake tab.
