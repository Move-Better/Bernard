This is not the on‑screen text. The words burned into the video live under Karaoke (formerly “Caps”). This field is the caption that publishes below the post.

What changes

  • New “Caption” tab in the reel/video editor, bound to the post caption (content_items.content) — the same save-on-blur textarea text posts already use, so the two can’t drift.
  • “Caps” → “Karaoke” so the burned-in on-screen words read as distinct from the post caption.
  • Opens on Caption first when a reel is opened from Publish, so it’s the first thing you see.

What stays the same

  • Every existing tool — Clip, Grade, on-screen captions, Music, Script, Text — is untouched.
  • The auto-drafted caption is already a real social caption (not the script); this just makes it visible and editable before you publish.
  • Standalone clip editing (Moment Miner, before a post exists) shows no Caption tab — there’s no post to caption yet.
